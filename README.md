# Universal safetensors Converter

This script will convert any .bin .pt .pth or .ckpt file to .SAFETENSORS

### Safetensor Converter_v3 Inspector
If you have issues when using the safetensor_converter_universal script to convert files to safetensors, you can use this script to analyse the file and make sure it's a valid .pt, .pth, .bin or .ckpt file

Run the script like this:  
`\path_to_python\python.exe safetensor_converter_v4_universal_inspector.py --inspect --unsafe "C:\path\to\file\FILE.pt"`  
The output will look something like this:  

  
![image](https://github.com/user-attachments/assets/dc15f213-25da-41cb-9b9a-33312d031dae)

### Safetensor Converter Universal  

This script will convert your .pt, .pth, .bin or .ckpt file and create a new safetensors file in the same directory.  

Run the script like this:  
`\path_to_python\python.exe safetensor_converter_universal.py --unsafe "C:\path\to\file\FILE.pt"`  
The output will look like this if you did everything correct:  

  
![image](https://github.com/user-attachments/assets/019ffc9f-7a49-42d0-9b49-34b889cd07e3)
